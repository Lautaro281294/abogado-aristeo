## 📋 Características

- **Diseño responsivo**: Se adapta perfectamente a dispositivos móviles, tablets y desktops
- **Interfaz elegante**: Paleta de colores cálida y profesional con tipografía serif y sans-serif

- **Accesibilidad**: Cumple con estándares WCAG (foco visible, contraste adecuado, navegación clara)
- **Performance**: Preload de fuentes, backdrop-filters optimizados, transiciones GPU
- **Mobile-first**: Menú hamburguesa responsive para dispositivos pequeños
